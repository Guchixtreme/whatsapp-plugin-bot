# ⚡ Guchi X WhatsApp Bot

A modular, high-performance WhatsApp assistant built with Node.js and Baileys.

## 🚀 One-Click Deployment

Click the button below to deploy **Guchi X** directly to your Render account:

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Guchixtreme/whatsapp-plugin-bot)

---

## 🛠️ Environment Variables

When deploying, set the following environment variable:
* `OWNER_NUMBER`: Your phone number with country code (e.g., `233XXXXXXXXX`)

---

## 💻 Local Setup

```bash
# Clone the repository
git clone [https://github.com/Guchixtreme/whatsapp-plugin-bot.git](https://github.com/Guchixtreme/whatsapp-plugin-bot.git)

# Install dependencies
cd whatsapp-plugin-bot
npm install

# Start the bot with pairing code
npm start
